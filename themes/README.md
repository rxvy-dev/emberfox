# Ignifox theme gallery

Every theme here shows up in **Ignifox Studio → Look & Color → Theme gallery** (desktop) and
**Ignifox Studio → Theme gallery** (Android). A theme is one `igni:` code: seven colours for
background, two surfaces, text, dim text, accent and second accent.

## Add yours

1. In Ignifox, make a theme (Studio → Look & Color → Palette editor) and press **Copy theme code**.
2. Open a [theme submission](https://github.com/rxvy-dev/ignifox/issues/new?template=theme.yml) and paste it,
   or add an entry to `index.json` in a pull request.

Every theme is checked automatically: text must be readable on its background (contrast 7:1 or
better) and the accent must stand out (3:1 or better).
